## 🔍 规则使用说明

每条规则文件包含以下标准结构：

```markdown
# 规则名称

## 基本信息
- **规则编号**: RULE-XXX-XXXXX
- **适用税种**: 增值税/企业所得税/个人所得税
- **风险等级**: 高/中/低
- **触发条件**: ...

## 检测逻辑
1. 数据提取：从[数据源]获取[字段]
2. 计算公式：...
3. 判断阈值：...

## 脱敏示例
（展示脱敏前后的数据对比）
```

## ⚠️ 重要提示

- 所有规则中的案例数据均为**虚拟脱敏数据**
- 实际使用时需替换为真实业务场景参数
- 规则阈值需根据最新税收政策定期更新
